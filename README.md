# pptx-service

A small Flask service that fills a PowerPoint template with slide titles and bullet points, for example ones generated by an AI model. You send a `.pptx` template and a JSON description of the deck, and get back a finished `.pptx`.

## Endpoints

### `GET /health`

Returns `{"status": "ok"}`.

### `POST /inject`

Multipart form with two fields:

| Field | Type | Description |
|---|---|---|
| `template` | file | The `.pptx` template. The first slide is used as the cover. |
| `data` | text (JSON) | `{"title": "...", "subtitle": "...", "slides": [{"title": "...", "bullets": ["...", "..."]}]}` |

Returns the finished presentation as `presentation_updated.pptx`.

How it works: the cover slide gets the title and subtitle, every other template slide is removed, and one new slide is added per item in `slides`, using the template's own title-and-content layout.

Errors come back as JSON with a short `error` message. Invalid JSON, an invalid template or too many slides return `400`, and an oversized upload returns `413`.

## Configuration

| Variable | Default | Description |
|---|---|---|
| `ALLOWED_ORIGINS` | `https://presentation-maker-xi.vercel.app,http://localhost:3000` | Comma-separated list of origins allowed to call the service from a browser (CORS). |
| `MAX_UPLOAD_MB` | `20` | Largest accepted upload, in megabytes. |

Limits: up to 60 slides and 30 bullets per slide.

## Run it

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000
```

Or with Docker:

```bash
docker build -t pptx-service .
docker run -p 5000:5000 pptx-service
```

The container runs gunicorn as a non-root user.

## Built with

Python, Flask, python-pptx, flask-cors and gunicorn.
